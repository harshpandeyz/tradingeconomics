# Global Economic Explorer
A responsive single-page web app for comparing economic indicators across countries using the Trading Economics API.

## How to run
Just open index.html in any browser. No installation needed.

## Features
- Compare any two countries on key indicators
- View historical trends with line charts
- Loading, empty-state, and API/auth fallback handling
- Built with vanilla JavaScript and Chart.js

## Tech Stack
HTML, CSS, JavaScript, Chart.js, Trading Economics REST API

## API Reference
https://docs.tradingeconomics.com
